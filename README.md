# Кофейная рулетка

**Открыть: https://socdevvv.github.io/coffee-roulette/**

Не знаешь, что заказать? Нажми «Крутить» — рулетка выберет напиток под настроение.

- Один файл `index.html`, без сборки и зависимостей.
- Фильтры: взбодриться, побаловать себя, холодное.
- Тёмная кофейная тема, адаптив под телефон.

Сделано за 20 минут по приколу.
